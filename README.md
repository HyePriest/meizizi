## 登录与本地保存

登录页可切换「百度登录 / QQ 登录」。QQ 登录通过百度官方第三方登录入口（`type=15`）进入腾讯 HTTPS 电脑版授权网页，可选择「密码登录」，再返回百度；切换回百度登录会恢复默认浏览器标识。需要 QQ 已关联目标百度账号。百度可能仍要求短信或其他安全验证，不能保证免短信登录。授权完成后点击「已完成登录，返回贴吧」确认账号。

密码和短信验证码只输入百度官方网页。App 从自身 WebView 读取必要的百度登录 Cookie，调用贴吧确认登录状态，再用 `flutter_secure_storage` 保存在手机本地；不保存密码，不输出凭证到日志，不上传到其他服务器。
最近浏览、屏蔽名单和未发送的文字草稿保存在手机本地。多个账号的 Cookie 和资料均由安全存储加密保存，切换时同步当前账号到应用自身 WebView。安卓备份已关闭，以防将登录凭证带入云备份。

Windows 项目与 Pub 缓存分别位于 E/C 盘，因此关闭 Kotlin 增量缓存，避免跨盘路径错误。

## 数据接口

通过 HTTPS 直接连接百度：

- `/c/f/frs/page`：吧帖子列表
- `/c/f/pb/page`：正文和楼层
- `/c/f/pb/floor`：楼中楼
- `/mo/q/seekforum`、`/mo/q/search/thread`：关键词搜索
- `/c/s/login`：登录账号确认与操作凭据
- `/c/f/excellent/personalized`：首页帖子
- `/c/f/forum/like`：关注的吧
- `/c/c/forum/sign`：单个吧签到
- `/c/c/agree/opAgree`：帖子、楼层和楼中楼点赞与取消点赞
- `/c/c/forum/like`、`/c/c/forum/unfavolike`：关注/取消关注
- `/c/f/forum/getLevelInfo`：吧内等级名称
- `/c/c/post/add`：文字回复

协议参考 [Tiebanana](https://github.com/Aobanana-chan/Tiebanana/blob/master/lib/common/API/TiebaNetAPI.dart) 和 [aiotieba](https://github.com/lumina37/aiotieba)。本项目独立实现界面、请求和解析，没有复制其客户端代码或素材。接口不具备平台官方的稳定性保证。

本轮做静态检查、公开接口只读核对和打包，不操作手机进行功能测试，也不使用账号自动点赞、关注、签到或发送内容。
